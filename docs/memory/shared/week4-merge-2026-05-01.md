### What was built

**Shared helper** — [`sentura/dashboard/src/lib/workspace/server-fs.ts`](../../../sentura/dashboard/src/lib/workspace/server-fs.ts):

| Export | Purpose |
|---|---|
| `getOpenClawWorkspaceRoot()` | `~/.openclaw/workspace/` (overridable via `OPENCLAW_WORKSPACE_DIR`) |
| `getTestRunsRoot()` | `~/.openclaw/test-runs/` (overridable via `SENTURA_TEST_RUNS_DIR`) |
| `safeJoinUnder(root, rel)` | Path-traversal guard — throws if `root + rel` escapes `root` |
| `listDirUnder(root, rel)` | dirent listing, hidden-prefix filtered, ENOENT → `[]` |
| `statUnder(root, rel)` | `{sizeBytes, modifiedAt}` or null if missing |
| `readTextUnder(root, rel)` | Returns text content or null |
| `readJson5Under(root, rel)` | Parses with `JSON5` (handles unquoted keys + trailing commas — required for Person B's orchestrator EKG entries) |
| `readJsonUnder(root, rel)` | Plain `JSON.parse` (correct for the test-runs files even though their extension is `.json5` — runner uses `JSON.stringify`) |

**Five new Route Handlers**:

| Path | Method | Returns |
|---|---|---|
| `/api/orchestrator/ekg` | GET | `{workspaceRoot, pillars: {capabilities, conflicts, insights, globalSops}, errors}` |
| `/api/testing/runs` | GET | `{runsRoot, runs: RunSummary[]}` (sorted by mtime desc) |
| `/api/testing/runs/[runId]` | GET | `{filename, modifiedAt, sizeBytes, data: SuiteRunResult}` (path-traversal guarded) |
| `/api/knowledge/agents` | GET | `{workspaceRoot, agents: [{agentId, ekgFiles: [{name, sizeBytes, modifiedAt}]}]}` (orchestrator + state hidden) |
| `/api/knowledge/agents/[agentId]/file/[filename]` | GET | `{name, content, sizeBytes, modifiedAt, contentType}` (path-traversal guarded, `.md`/`.json5` allowlist) |

**Three rebuilt pages**:

- `/orchestrator/page.tsx` — 4-tab pillar browser. Capabilities tab renders a real table from JSON5 EKG entries (per-employee `name`/`agentId`/`department`/`capabilityTags` with overflow badge/`approvalsRequired` count/`deployedAt`/`provenance.confidence`). Other 3 pillars render honest empty states naming the W5 Manager skills.
- `/testing/page.tsx` — split-pane viewer. Runs index left (pass-rate badge with colored progress bar — green ≥0.75, amber below; recommendation pill deploy/auto-tune/block; iteration count; relative age). Detail pane right (4 summary chips + per-case table with safety-prefix highlight).
- `/knowledge/page.tsx` — 3-pane browser. Agent picker → file list → `<pre>` preview with content-type badge + size + mtime. Auto-selects first agent with files.

**Person C bug fix** — `/tune/page.tsx` was hitting a Next.js 16 `useSearchParams()` Suspense boundary error during `next build` (pre-existing, never built clean). Wrapped the inner component in `<Suspense fallback={null}>` mirroring the pattern Person C already used in `/chat/page.tsx`.
