# Cross-Border Mobile Accessories Ontology

Client-pilot ontology for Cross-border e-commerce / 跨境电商 employees serving a B2B exporter of mobile-phone accessories.

## What's Included

### `assets/`
- Product taxonomy for phone cases, screen protectors, chargers, cables, mobile holders, power accessories, and repair accessories.
- Buyer personas and country/language focus for Phase 1.

### `rules/`
- Contextual buyer-authenticity scoring rules.
- Evidence-block status semantics that separate normalized score from evidence coverage.
- Forced downgrade rules for high-risk contradictions.

### `workflows/`
- Lead-discovery SOP for Marketing Acquisition employees.
- Buyer-screening SOP for Screening and Background employees.

## Usage

Select this ontology when creating Cross-border e-commerce employees for mobile-accessory lead discovery, buyer screening, or Accio chat memory processing. It is intentionally client-lane specific and is not part of the generic `e-commerce` ontology.

## Safety

Phase 1 does not send cold outreach, scrape login-gated social media, or treat missing paid trade data as fraud evidence.
