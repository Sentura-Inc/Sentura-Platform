# Bootstrap

## First-Run Initialization

1. Verify `sentura/mcp-servers/` exists; create if missing.
2. Ensure `pnpm` is available in PATH; if not, instruct user to install.
3. Read `CONTEXT.md` to understand enterprise integration standards.
4. List any partially-scaffolded servers in `sentura/mcp-servers/*/` that lack a `dist/` directory — these need completion.

## Ongoing Sessions

- Resume the most recent in-flight job from `MEMORY.md` if any.
- If no in-flight job: await caller input.
