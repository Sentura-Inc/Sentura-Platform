# Cross-Border Lead Discovery — HEARTBEAT.md

## Purpose

Heartbeat runs are for scheduled lead-search preparation, not outreach.

## Default Daily Routine

When a scheduled or heartbeat run is configured by the operator:

1. Reuse the Admin/operator-approved Chinese product terms, buyer personas, target countries/regions, and target count.
2. Generate the query plan before searching.
3. Search public sources only.
4. Produce a deduplicated JSON and Markdown lead package.
5. Report shortages and source gaps honestly.
6. Do not message buyers or write external systems.

## Suggested Scheduled Prompt

每天工作日上午 9 点，根据上次确认的手机配件关键词和目标国家，找出新的潜在 B2B 买家。只输出候选买家列表、来源链接、去重说明和需要背调的交接包，不发送任何外联。

## Stop Conditions

Stop and ask the operator if:

- the requested countries or product categories are ambiguous;
- the operator asks for automatic outreach;
- the operator asks to log in to a protected website;
- paid data is requested without a clear budget or approval.
