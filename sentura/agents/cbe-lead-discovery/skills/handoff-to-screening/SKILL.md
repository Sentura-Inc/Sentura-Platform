# Handoff To Screening

## When To Use

Use when the operator selects candidate leads and asks to send them to Screening, prepare a background-check batch, export selected leads, or create a Screening handoff package.

## Milestone 4 Boundary

In Milestone 4, `cbe-buyer-screening` may not be deployed yet. If the Screening employee or dashboard route is unavailable, produce a typed handoff payload and tell the operator that it is ready for Screening once Milestone 5 is connected. Do not claim an investigation has started.

## Procedure

1. Accept selected `LeadCandidate` records only.
2. Validate each selected lead has:
   - `lead_id`;
   - `company_name`;
   - `country`;
   - `dedupe_key`;
   - `source_urls`;
   - `matched_products`;
   - `buyer_type`.
3. Convert each lead into an investigation target:

```json
{
  "target_id": "screening_target_lead_20260608_0001",
  "source": "marketing_lead",
  "lead_id": "lead_20260608_0001",
  "company_name": "Example Mobile Distribution Ltd",
  "country": "GB",
  "website": "https://example-mobile-distribution.co.uk",
  "domain": "example-mobile-distribution.co.uk",
  "email": "sales@example-mobile-distribution.co.uk",
  "product_interest": ["phone case", "screen protector"],
  "operator_notes": "Source count 3; public-web lead generated by cbe-lead-discovery.",
  "supplied_fields": ["company_name", "country", "website", "domain", "product_interest"],
  "inferred_fields": [],
  "missing_fields": ["registry_number", "trade_records", "financial_filing"]
}
```

4. Preserve provenance in the batch:
   - source run id;
   - selected lead ids;
   - source URLs;
   - query strings when available;
   - created timestamp;
   - handoff timestamp.
5. Output both:
   - machine JSON for the dashboard/Screening route;
   - Chinese operator summary.

## Handoff Package Shape

```json
{
  "handoff_id": "handoff_20260608_001",
  "from_agent": "cbe-lead-discovery",
  "to_agent": "cbe-buyer-screening",
  "status": "ready_for_screening",
  "source_run_id": "lead-run-2026-06-08-us-gb",
  "targets": [],
  "source_references": [],
  "created_at": "2026-06-08T00:00:00Z"
}
```

## Safety

- Do not send the selected contacts any message.
- Do not write to CRM or external systems.
- Do not drop source references during conversion.
- Do not score authenticity here; Screening owns score and evidence coverage.
